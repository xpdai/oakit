# 音樂課程年齡分班與價格翻卡設計

## 目標

將音樂首頁的年齡分班與價格合併成同一組翻卡，減少獨立區塊，讓訪客直接在
年齡卡片內查看對應費用；同時把課程方式放到年齡分班與價格之前。

## 版面順序

音樂首頁的課程區塊順序改為：

1. `課程方式`
2. `年齡分班與價格`

原本獨立的「服務與價格」網站區塊不再渲染。租戶資料中的 `services` 保留，
繼續供 LINE 知識庫與價格回覆使用。

## 卡片內容與互動

### 課程方式

沿用現有翻卡互動，新增一張「試上一堂」卡片。卡片正面顯示課程體驗名稱，
反面顯示目前的試上課介紹、既有服務資料的 `NT$100／堂` 與 `30 分鐘`。

### 年齡分班與價格

標題從「年齡分班」改為「年齡分班與價格」。四張年齡卡片都保留現有類別、
課程名稱與簡介在正面；翻面後顯示對應服務資料的價格與每堂時長：

- 個別（18歲以下）／鋼琴一對一：顯示初階、進階、高階價格與 50 分鐘。
- 兒童、成人、樂齡團班：顯示 NT$450／人／堂與 50 分鐘。

價格以既有 `services` 資料為來源，不新增第二份價格資料，避免官網與 LINE
回答不一致。若服務資料缺少價格，卡片反面顯示準備中的保底文字，不輸出空白。

## 實作範圍

- `src/site/variants.ts`：調整音樂區塊渲染順序、標題、年齡卡片正反面內容，
  並從服務資料組合價格背面。
- `tenants/demo-music.json`：在 `site.showcase` 新增「試上一堂」課程方式卡片。
- `src/site/render.ts`：音樂首頁不再輸出獨立 `servicesSection`。
- `tests/site-render.test.ts`、`tests/knowledge.test.ts`：鎖定順序、標題、卡片
  數量、價格內容與服務區塊不渲染；確認 LINE 知識庫仍保留服務價格。

## 驗收條件

- 「課程方式」出現在「年齡分班與價格」之前。
- 課程方式共有三張卡片，包含「試上一堂」。
- 年齡分班與價格共有四張翻卡；正面有原本簡介，反面有對應價格。
- 音樂首頁沒有獨立 `id="services"` 區塊。
- 「試上一堂」翻面顯示 `NT$100／堂` 與 `30 分鐘`；年齡卡片反面顯示各自價格與時長。
- 現有測試、型別檢查、建置與差異檢查通過，其他 demo 不受影響。
