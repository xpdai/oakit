# 那莫好聽 Logo 獨立元件動畫設計

日期：2026-08-08  
狀態：設計內容已確認，等待文件審閱

## 目標

將目前使用單一 Logo 圖片裁切的動畫，改成由獨立生成的 Logo 元件合成。動畫完成後，視覺上仍要回到目前「那莫好聽」Logo 的構圖與手繪風格。

原本的 `assets/na-mo-logo.jpg` 只作為風格、比例與構圖參考，不再用它的局部內容做動畫裁切。

## 元件範圍

動畫使用 6 個獨立素材：

1. 圓環與內圈
2. 左側樹枝
3. 右側樹枝
4. 中央麥克風
5. 右側小鳥
6. 周圍音符

每個素材都使用相同的正方形畫布基準與透明背景，讓它們可以在相同座標系統中合成。素材預計放在 `assets/music-logo/`：

- `ring.png`
- `forest-left.png`
- `forest-right.png`
- `microphone.png`
- `bird.png`
- `notes.png`

生成時以目前 Logo 作為風格參考，保留米色、深咖啡、橄欖綠、橘色與藍綠色的手繪配色，不加入文字、水印或額外角色。

所有獨立元件必須保留完整內容，尤其 `forest-right.png` 不可在素材檔內預先裁掉上半部。左右樹枝、小鳥與音符的透明邊緣外增加約 6px 的暖白色外框（目標色 `#fff7e8`），模擬原圖中元件與米色底之間的淺色留白；圓環與麥克風不新增此外框。

## 音符位置校正

`notes.png` 使用 758 × 758 的透明畫布，三顆音符分開校正，不再把整組音符一起縮放。位置依原圖量測結果設定：

- 左側小音符：邊界約為 `x 62–111 / y 166–233`，位於圓環左外側。
- 右上第一顆音符：邊界約為 `x 565–629 / y 44–125`，位於圓環上方外側。
- 右側第二顆音符：邊界約為 `x 666–727 / y 176–259`，位於圓環右外側。

三顆音符都要有同樣的暖白外框，且音符圖層位於整個動態合成的最上層。三顆音符都必須位於圓環外，不得與圓環、麥克風、樹枝或小鳥重疊。

## 圓環內部去背

`ring.png` 的外圈圖案與深色邊框保留，內圈填色全部去背為透明，讓頁面背景直接穿過圓環；麥克風與其他元件仍由各自圖層顯示，不使用白色圓形底填補內圈。

## 合成結構

網頁會在同一個 Logo 容器內使用獨立圖層合成：

```text
頁面米色背景
└── Logo 合成容器
    ├── 圓環與內圈
    ├── 左側樹枝
    ├── 右側樹枝
    ├── 音符
    ├── 麥克風
    └── 小鳥
```

動畫中的合成順序為：背景 → 完整右樹枝 → 圓環 → 麥克風 → 左樹枝 → 小鳥 → 音符。音符必須是最高元件圖層。右樹枝不能裁切，圓環圖層覆蓋它的上半部，枝條下半部與尾巴在圓圈外自然露出。完成狀態的元件位置與大小要對齊目前 Logo；動畫不得使用現有 JPG 的 `clip-path`、背景裁切或複製圖片局部來模擬元件。

動畫與完成圖都使用完整的右樹枝素材，只靠右樹枝位於圓環下方形成遮擋關係；不得建立或寫回任何裁切版 `forest-right.png`。動畫結束後，獨立圖層淡出，只留下完整元件合成的 `combined.png`，避免兩組 Logo 重疊。

## 動畫行為

- 0–1.3 秒：左右樹枝從兩側進場，輕微搖曳並靠近圓環。
- 0.7–2.9 秒：小鳥從左側穿梭，最後停在 Logo 右側。
- 1.8–3.8 秒：麥克風從遠處的小比例逐漸放大並靠近中心。
- 3.2–4.2 秒：音符依序淡入。
- 4.2 秒後：所有元件對齊，形成完整 Logo 並保持穩定。

動畫只在頁面載入時播放一次。手機版使用同一個合成容器等比例縮放，不改變元件相對位置。

## 無障礙與備援

- `prefers-reduced-motion: reduce` 時直接顯示完成後的靜態元件合成，不播放位移、縮放與旋轉。
- 動畫元件使用 `aria-hidden="true"`，避免螢幕閱讀器重複讀取裝飾圖層。
- 既有 Logo JPG 保留作為非音樂頁面與素材載入失敗時的備援，不影響其他 demo。

## 驗證標準

1. 每個元件都是獨立素材，網站動畫 HTML 不含現有 Logo 圖片的裁切動畫。
2. 完成狀態能以新元件合成出目前 Logo 的主要構圖、配色與比例；右樹枝素材與完成圖都維持完整，只由圓環圖層遮住上半部。
3. 圓環內圈為透明，三顆音符均位於圓環外且不與其他 Logo 元件重疊。
4. 初始動畫符合樹枝靠近、小鳥穿梭、麥克風由遠到近的順序。
5. 手機版元件不錯位，Logo 不遮住其他互動元素。
6. 減少動態效果設定能直接顯示完整 Logo。
7. `npm test`、`npm run typecheck`、`npm run build` 與 `git diff --check` 通過。
8. 音符位置符合三組量測邊界，樹枝、音符與小鳥都有一致的暖白外框。
9. 用瀏覽器檢查本機與線上頁面的初始狀態、完成狀態及 console 錯誤。
