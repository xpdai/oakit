# 音樂課程時長與價格換行設計

## 目標

讓那莫好聽的團體班清楚標示每堂 50 分鐘，並讓一對一課程的初階、進階、高階價格在手機與桌機上各自獨立一行，避免價格資訊擠在同一行。

## 設計

- `tenants/demo-music.json` 仍是唯一內容來源。
- 團體班服務的 `duration` 改為「每堂 50 分鐘」；三人開班與最多三人的說明保留在課程描述中。
- 團班的「課程方式」展示資訊同步補上每堂 50 分鐘。
- 一對一服務價格與展示資訊使用換行字串保存，渲染時以音樂版專用 CSS `white-space: pre-line` 呈現；其他網站版型不改變。
- 測試會檢查團班服務與展示資訊都包含 50 分鐘，也會檢查音樂版價格區塊啟用換行樣式並保留三個級別文字。

## 驗收條件

1. 團班課程卡顯示「每堂 50 分鐘」。
2. 課程方式中的團班展示資訊顯示「每堂 50 分鐘」。
3. 一對一課程的初階、進階、高階價格各自換行，不再排在同一行。
4. 其他 demo 版型與既有價格顯示不受影響。
5. `npm run typecheck`、`npm test`、`npm run build` 與 `git diff --check` 通過。
