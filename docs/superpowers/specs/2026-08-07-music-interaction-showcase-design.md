# 音樂版互動與示意作品設計

## 目標

保留那莫好聽目前的奶油色品牌底與內容，加入參考 Magic UI 的互動質感；照片與作品先用 GPT 生成示意素材，並清楚標示為非真實學生作品。

## 視覺方向

- 保留 `#f8e8c8` 奶油背景、深棕文字與現有 Logo。
- 動畫重點放在滑鼠／觸控互動、卡片聚焦與圖片揭示，不改成深色科技主題。
- 互動元素使用音樂教室語彙：柔和聚光、波形、演奏卡片與練習進度線；減少全頁飄浮音符，避免模板感。
- 所有互動都支援鍵盤 focus，並在 `prefers-reduced-motion: reduce` 時停用位移與轉場。

## 互動範圍

1. Hero：滑鼠移動時產生低幅度聚光與內容視差；離開後回到原位。
2. 年齡分班：卡片 hover／focus 顯示局部強調線與內容浮起，不改變閱讀順序。
3. 課程方式：卡片滑入時依序揭示類別、課名、說明與價格資訊。
4. 雲端成發：顯示三張 GPT 生成的示意圖片；點擊圖片開啟同頁 lightbox，Esc 或點擊背景關閉。
5. 示意作品卡：每張標示「示意素材｜非真實學生作品」，不提供看似真實的學生姓名或成績宣稱。

## 資料與資產

- `assets/music/` 存放生成的房間、練琴與演出示意圖；圖片不得依賴外部 CDN。
- `StudentShowcaseItem` 增加可選 `image` 與 `imageAlt` 欄位，仍由 `tenants/demo-music.json` 控制內容。
- 生成圖片只作為視覺示意；未來替換為真實作品時，只需替換 tenant 圖片路徑與文字，不需改渲染邏輯。

## 驗收條件

1. 奶油色品牌視覺、價格、年齡分班與既有文案保留。
2. 滑鼠移動、卡片 hover／focus、滾動揭示與 lightbox 均可操作。
3. Lightbox 可用 Esc 關閉，圖片有適當 `alt`，背景不可滾動穿透。
4. 其他 demo 不輸出音樂圖片與音樂互動。
5. reduced motion 下不產生強制位移或閃爍。
6. 通過 `npm run typecheck`、`npm test`、`npm run build` 與 `git diff --check`。
