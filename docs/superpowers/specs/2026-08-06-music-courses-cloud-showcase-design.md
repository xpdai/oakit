# 那莫好聽課程與雲端成發設計

## 目標

更新「那莫好聽」音樂教室目前的課程內容與價格，明確呈現流行／古典、
一對一與成人限定團體班的規則，並在網站新增「雲端成發」專區，讓未來可
放入學生課堂作品連結，呈現學習成長。

## 已確認的內容

- 課程方向：流行與古典。
- 課別：一對一與團體班；團體班限成人。
- 免費試上課：30 分鐘。
- 鋼琴一對一：NT$3,600／4 堂，每堂 50 分鐘；換算為每堂 NT$900。
- 成人團體班：NT$450／人／堂，3 人即開班，最多 3 人。
- 團體班文案需說明人數上限是為了維持教學品質。
- 目前沒有可使用的影片、音檔或雲端連結；網站先顯示清楚的「作品整理中」空狀態，不放虛構作品。

## 設計方案

### 1. 租戶資料模型

在 `src/tenant.ts` 新增音樂教室學生作品的資料型別，並在 `SiteContent` 加上
可選的 `studentShowcase`：

```ts
export interface StudentShowcaseItem {
  title: string;
  category?: string;
  description: string;
  meta?: string;
  url?: string;
}

export interface SiteContent {
  // existing fields...
  studentShowcase?: StudentShowcaseItem[];
}
```

這個欄位只負責網站展示，不會引入外部圖片、字型、CDN 或框架。未來填入
`url` 時，只接受 `http:`／`https:` 連結，並使用既有的安全 URL 檢查邏輯；
不安全的連結不渲染成可點擊按鈕。

### 2. 課程與 FAQ

將 `tenants/demo-music.json` 的 `services` 改成三項，移除吉他、樂團與歌唱
等目前沒有提供的內容，讓價格、時長與規則在
官網和 LINE 知識庫共用同一份資料：

1. `鋼琴一對一｜流行與古典`：流行或古典方向皆可，NT$3,600／4 堂（每堂
   NT$900），每堂 50 分鐘。
2. `成人團體班｜流行與古典`：成人限定，NT$450／人／堂，3 人即開班，最多
   3 人，並說明小班人數是為了維持教學品質。
3. `免費試上課`：30 分鐘，價格顯示為免費。

品牌介紹、首頁特色、課程展示與 FAQ 會同步移除吉他、樂團、歌唱等不提供
的服務，只保留鋼琴的流行／古典方向，以及成人團體班規則。FAQ 會同步調整
為免費試上課、團體班成人資格／開班人數與鋼琴學習問題，避免網站和 LINE
對價格、試上時間或課程範圍說法不一致。

### 3. 網站區塊與互動

在 `src/site/variants.ts` 新增音樂教室專用的 `studentShowcase` renderer，並
在 `src/site/render.ts`：

- 僅在 `site.variant === 'music'` 時加入導覽連結「雲端成發」。
- 在課程展示區後加入獨立的 `<section id="student-showcase">`。
- 有作品資料時，渲染標題、分類、說明、補充資訊，以及安全的「觀看作品」連結。
- 沒有作品資料時，渲染「學生作品整理中」空狀態，說明這個區域將分享課堂
  上完成的曲子與學習成長，讓訪客知道這不是載入失敗。

樣式沿用現有米色背景、深棕文字與橘／綠 Logo 色調；作品卡採安靜的卡片
排列，桌面版兩欄、手機版單欄，按鈕沿用既有 focus-visible 與 reduced-motion
規則。新增區塊不使用影片自動播放，也不產生外部資源標籤。

### 4. LINE 知識庫

因為 `buildKnowledge` 已從 `services` 與 FAQ 自動產生文字，課程價格與試上／
團班規則不需要另寫一份回覆。若 `studentShowcase` 未來有作品，知識庫同步
列出作品標題與說明；目前空陣列不產生虛構作品資訊。

## 驗收條件

- 官網顯示流行與古典方向、一對一、成人團體班與免費 30 分鐘試上課。
- 官網與 LINE 內容不再列出吉他、樂團或歌唱課程。
- 官網顯示鋼琴一對一 `NT$3,600／4 堂`、每堂 50 分鐘，以及團體班
  `NT$450／人／堂`、3 人開班、最多 3 人。
- 官網有可由導覽進入的「雲端成發」區塊；目前顯示作品整理中的空狀態。
- `buildKnowledge` 與 LINE 價格規則回覆包含更新後的課程資料。
- 所有租戶輸入仍經過 HTML escaping；作品連結只接受安全的 HTTP(S) URL。
- 不出現外部資源標籤，不恢復營業時間區塊，不修改其他 demo。
- `npm run typecheck`、`npm test`、`npm run build` 與 `git diff --check` 全部通過。
- 產出的 `dist/demo-music/index.html` 包含品牌名稱、Logo、正確聯絡方式、
  更新後課程與「雲端成發」。
